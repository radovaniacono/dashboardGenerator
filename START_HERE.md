## ❓ Help

### Ho errori di installazione
```bash
# Aggiorna pip
pip install --upgrade pip

# Installa con verbose
pip install -r requirements.txt -v
```

### L'app non parte
```bash
# Verifica Python
python --version

# Prova con porta diversa
streamlit run app.py --server.port 8502
```

### Il file non carica
```
✅ Verifica: File è CSV/Excel/JSON?
✅ Verificare: Encoding è UTF-8?
✅ Verificare: File non è corrotto?
```

Per più help → Vedi [QUICK_START.md](QUICK_START.md) Troubleshooting
